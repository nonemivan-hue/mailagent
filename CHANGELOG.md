# История изменений (Changelog)

## Версия 1.4.6 — 17.08.2026

### Исправления

#### 1. Исправлены ошибки IMAP "socket error: EOF" и "SELECT illegal in state LOGOUT"
- **Причина:** IMAP-сервер разрывал соединение по таймауту. При следующем цикле программа пыталась выполнить SELECT на закрытом сокете.
- **Решение:**
  - Улучшен `_ensure_imap_connected()` — при ошибке NOOP принудительно закрывается старое соединение (`logout()`), обнуляется сокет и создаётся новое подключение.
  - Добавлена защитная обёртка вокруг `select("INBOX")` в `receive_emails` и `process_auto_receive` — при ошибке SELECT выполняется автоматическое переподключение и повторная попытка.
  - Удалён дублирующийся метод `_ensure_imap_connected`.

## Версия 1.4.5 — 14.08.2026

### Исправления

#### 1. Исправлено окно настроек подключения
- **Проблема:** Вкладка "Подключение" не имела прокрутки, часть настроек сервера могла быть недоступна при размере окна 700×580.
- **Решение:** Добавлен Canvas + Scrollbar во вкладку "Подключение". Все настройки сервера (IMAP/SMTP порты, шифрование, аутентификация, имена пользователей) теперь прокручиваются колесом мыши.

#### 2. Добавлена недостающая вкладка "Дополнительно"
- **Проблема:** Метод `_create_advanced_tab` отсутствовал, при открытии настроек возникала ошибка `AttributeError`.
- **Решение:** Добавлена вкладка "Дополнительно" с полями:
  - Интервал проверки отправки (сек)
  - Интервал проверки приема (сек)
  - Имя папки отправленных на сервере
  - Галочка "Сохранять отправленные письма на сервере"
  - Текстовое поле для подписи исходящих писем

#### 3. Уменьшены размеры элементов главного окна
- График статистики уменьшен (`figsize=(3.5, 2.2)`, `dpi=90`) для экономии места.
- Высота таблиц истории отправленных/полученных писем уменьшена (`height=8` вместо 12).

#### 4. Обновлена документация и файлы установщика
- Обновлен `README.md` — добавлено описание всех возможностей v1.4.5.
- Обновлен `INSTRUCTION_INSTALL.md` — дополнена инструкция по созданию установщика Windows.
- Обновлен `setup.iss` — версия 1.4.5, добавлены все необходимые файлы в установщик.

## Версия 1.4.4 — 14.08.2026

### Исправления

#### 1. Повторная отправка при разрыве SMTP-соединения
- **Ошибка:** `Server not connected` при отправке нескольких файлов одним письмом.
- **Причина:** После успешной отправки первого письма SMTP-сервер закрывал соединение. При попытке отправить следующее письмо объект `smtplib.SMTP` существовал, но сокет был закрыт.
- **Решение:** Добавлен метод `_sendmail_with_retry()` с 3 попытками отправки. При ошибке `SMTPServerDisconnected` / `SMTPConnectError` / `ConnectionError` соединение автоматически пересоздаётся и отправка повторяется.

## Версия 1.4.2 — 13.08.2026

### Исправления

#### 1. Автоматическое переподключение SMTP/IMAP
- **Ошибка:** `please run connect() first` при отправке писем после длительного простоя.
- **Причина:** Сервер разрывал соединение по таймауту, объект `smtplib.SMTP` оставался в памяти, но `self.sock` был `None`.
- **Решение:** Добавлены методы `_ensure_imap_connected()` и `_ensure_smtp_connected()`. Перед каждой операцией отправки/приема проверяется активность соединения через `noop()` (IMAP) и `ehlo()` (SMTP). При разрыве — автоматическое переподключение.

### Исправления ошибок

#### 1. TclError: invalid command name ".!toplevel2.!frame.!canvas"
- **Причина:** `canvas.bind_all("<MouseWheel>", ...)` привязывал обработчик глобально. При закрытии окна настроек Canvas уничтожался, но бинд оставался.
- **Исправление:** `bind_all` заменён на `bind` к конкретному окну + защита `try/except` + `winfo_exists()`.

#### 2. SMTPUTF8 capability
- **Ошибка:** `One or more source or delivery addresses require internationalized email support, but the server does not advertise the required SMTPUTF8 capability`
- **Причина:** `send_message()` требовала SMTPUTF8 для не-ASCII адресов/тем, но сервер (mail.ru) не поддерживает.
- **Исправление:** Замена `send_message()` на `sendmail()` + переход с `MIMEMultipart`/`MIMEText`/`Header` на `EmailMessage`.

#### 3. 'utf8' is an invalid keyword argument for Compat32
- **Ошибка:** `'utf8' is an invalid keyword argument for Compat32`
- **Причина:** В Python 3.14 старый email-API (`MIMEText` с политикой `Compat32`) ломается на `charset='utf-8'`.
- **Исправление:** Переход на `EmailMessage` с `set_content()` и `add_attachment()`. Новый API не использует `Compat32`.

#### 4. SyntaxWarning: invalid escape sequence
- **Ошибка:** `SyntaxWarning: invalid escape sequence '\S'` / `'\D'`
- **Причина:** Строки `\Seen` и `\Deleted` интерпретировались как escape-последовательности Python.
- **Исправление:** Использование raw-строк (`r'\Seen'`, `r'\Deleted'`).

### Технические изменения

- Добавлен импорт `from email.message import EmailMessage`
- Удалены импорты `MIMEText`, `MIMEBase`, `encode_base64`, `Header` (где не используются)
- Все 3 места отправки переписаны на `EmailMessage`:
  1. Основная отправка из папки `send_folder`
  2. Авто-отправка (один файл)
  3. Авто-отправка (несколько файлов)
- `_save_to_sent_folder()` адаптирован для работы с `EmailMessage`
- `mail_config.json` теперь сохраняет `window_geometry` и `multi_files`
