# Автопроцессинг электронной почты v1.4.5

## Назначение

Данная программа разработана для использования УЗСНами Краснодарского края.

Приложение для автоматической отправки и приема электронной почты через IMAP/SMTP с возможностью работы в системном трее.

## Основные возможности

- Автоматическая отправка файлов из заданных папок по SMTP
- Автоматический прием писем с сохранением вложений в структурированные папки
- Поддержка дополнительных правил авто-отправки и авто-приема
- Архивация отправленных/полученных писем в ZIP
- Системный трей (сворачивание при закрытии окна)
- График трафика и статистика (текущая сессия + за все время)
- Окна истории отправленных и полученных писем с фильтрами и сортировкой
- Поддержка нескольких файлов одним письмом в авто-правилах
- Автоопределение настроек серверов по домену email (Mail.ru, Yandex, Gmail, Outlook и др.)
- Резервное копирование и восстановление настроек
- Обновление программы из ZIP-архива

## Файлы конфигурации

| Файл | Назначение |
|------|------------|
| `mail_config.json` | Основные настройки учетной записи и папок |
| `mail_stats.json` | Статистика за все время |
| `sent_history.json` | История отправленных писем |
| `received_history.json` | История полученных писем |
| `mail_app.log` | Технический журнал работы |
| `sent_log.txt` | Журнал операций отправки |
| `received_log.txt` | Журнал операций приема |

## Запуск

```bash
python mail_auto_processor.py
```

## Обновление

Программа поддерживает обновление через кнопку "Обновить" в главном окне. Также можно использовать скрипты `update.bat` (Windows) или `update.sh` (Alt Linux).
